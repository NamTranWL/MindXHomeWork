## Nhắc nhanh
7 bước: Reception (<15') → Response (<30') → Diagnosis → Resolution → Communication (24h) → Follow-up → Trend Analysis
Class: Standard <5 · Priority 5–25 · Expedite >25 · Fixed Deadline
Không hứa ETA cố định. Chỉ đóng ticket khi đã có xác nhận.

## Acceptance criteria
- [ ] Hoàn thành 6 scenario, áp dụng đúng 7 bước
- [ ] Phân loại Class of Service chính xác
- [ ] ACK kịp thời, không hứa ETA cố định
- [ ] Email draft chuyên nghiệp (ACK / update / resolution) cho mỗi scenario
- [ ] Ticket Odoo tạo/cập nhật đúng, tag đúng, theo template
